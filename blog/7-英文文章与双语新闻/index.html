Программа для чтения двуязычных книг

Программа 'EasyLang' специально создавалась для комфортного чтения параллельных текстов.
Чтение в программе двуязычной книги с подстрочником будет более продуктивным.
Подстрочник мгновенно предоставит варианты перевода для выделенного фрагмента текста.
В программу встроены сервисы для подсветки и перевода идиом.
Для старта в программу включено несколько двуязычных книг.

Как быть если нет параллельной копии текста?

EasyLang позволит комфортно читать иностранный текст без переключения на дополнительные словари и переводчики.
Программа содержит в себе сервис автоматического перевода от Google и Microsoft.
